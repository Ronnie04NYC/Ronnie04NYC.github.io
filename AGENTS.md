# Website development

- Keep Astro static output compatible with GitHub Pages.
- Preserve the npm lockfile and run `npm run check` and `npm run build` before publishing.
- Use `codex/` branches for iterative changes and describe validation in pull requests.
- Keep private project reference files, credentials, and personal data out of this public repository.
- Do not invent project URLs, essays, quotes, or contact details.
- Reuse the shared layout, site data, and stylesheet when adding pages.
- Deploy through `.github/workflows/deploy.yml`; no additional hosting platform is needed.
